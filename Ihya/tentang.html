SIAPA KAMI?

Tentang List dalam HTML

List merupakan elemen HTML yang digunakan untuk menyusun informasi menjadi sebuah daftar agar lebih rapi, terstruktur, dan mudah dibaca.

Apa Itu List HTML?

List dalam HTML adalah kumpulan item yang ditampilkan sebagai daftar. List berguna untuk menyusun langkah-langkah, kumpulan informasi, istilah beserta definisinya, dan pilihan menu.

Penggunaan list yang tepat juga membantu meningkatkan keterbacaan konten dan mendukung aksesibilitas website, terutama bagi pengguna pembaca layar.

MATERI UTAMA

Empat Jenis List dalam HTML

Kenali fungsi setiap elemen beserta contoh implementasinya.

1.

Ordered List (<ol>)

Digunakan untuk membuat daftar berurutan, biasanya menggunakan angka atau huruf. 

<ol>
  <li>Persiapan</li>
  <li>Pelaksanaan</li>
  <li>Evaluasi</li>
</ol>

Hasil:

  1. Persiapan
  2. Pelaksanaan
  3. Evaluasi
•

Unordered List (<ul>)

Digunakan untuk membuat daftar tanpa urutan khusus, biasanya menggunakan tanda bullet. 

<ul>
  <li>HTML</li>
  <li>CSS</li>
  <li>JavaScript</li>
</ul>

Hasil:

  • HTML
  • CSS
  • JavaScript
Aa

Description List (<dl>)

Digunakan untuk menampilkan istilah dan penjelasannya dengan elemen <dt> dan <dd>. 

<dl>
  <dt>HTML</dt>
  <dd>Struktur halaman web</dd>
</dl>

Hasil:

HTML
Struktur halaman web.
☰

Menu (<menu>)

Digunakan untuk merepresentasikan daftar item atau perintah menu. Bentuk tampilannya umumnya mirip dengan daftar tidak berurutan. 

<menu>
  <li>Beranda</li>
  <li>Artikel</li>
  <li>Kontak</li>
</menu>

Hasil:

  • Beranda
  • Artikel
  • Kontak

    PRAKTIK LANGSUNG

    Implementasi List dalam HTML

    Berikut contoh penerapan beberapa jenis list untuk kebutuhan website sehari-hari.

    1. Daftar Langkah Belajar Web

    Gunakan <ol> jika urutan langkah penting.

    1. Pelajari struktur dasar HTML.
    2. Gunakan CSS untuk mengatur tampilan.
    3. Tambahkan JavaScript untuk interaksi.
    4. Uji halaman di browser.

    2. Daftar Teknologi Web

    Gunakan <ul> jika urutan tidak penting.

    • HTML untuk struktur konten.
    • CSS untuk desain halaman.
    • JavaScript untuk interaksi.

    3. Glosarium Istilah

    Gunakan <dl> untuk istilah dan definisi.

    Elemen
    Bagian dokumen HTML yang dibentuk menggunakan tag dan konten.
    Atribut
    Informasi tambahan yang diberikan pada elemen HTML.
    Selector
    Pola yang digunakan CSS untuk memilih elemen yang akan diberi gaya.

    4. Daftar Menu Website

    Gunakan <menu> untuk mengelompokkan item menu.
